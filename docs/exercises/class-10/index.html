  2. Recall the usual Causal Inference setup from the last lecture. We consider a treatment variable \(D\), outcome \(Y\), and possibly a vector of covariates \(X\); all random variables from some distribution \((Y, D, X) \sim P\). As our data we consider a random sample of \(n\) units from distribution i.e. \(\{(Y_{i}, D_{i}, X_{i})\}_{i=1}^{n}\).

    We define unit \(i\)’s potential outcomes under two hypothetical intervations as \(Y_{i}(1), Y_{i}(0)\).

    The observed outcome \(Y_{i}\), which can be written in terms of the potential outcomes as \[\begin{align} Y_{i} & = \begin{cases} Y_{i}(1), & D_{i} = 1 \\ Y_{i}(0), & D_{i} = 0 \end{cases} \\ & = Y_{i}(0) + D_{i}\{Y_{i}(1) - Y_{i}(0)\}. \end{align} \tag{1}\]

    To see how effective the treatment \(D\) is on our \(Y\), we could compare the averages of \(Y\) across \((D = 1)\) and \((D = 0)\) i.e. the naive comparison \(E[Y_{i} \mid D_{i} = 1] - E[Y_{i} \mid D_{i} = 0]\).

    1. Show how we can go from the naive comparison to the expression from the slides:

      \[\begin{align*} & E[Y_{i} \mid D_{i} = 1] - E[Y_{i} \mid D_{i} = 0] \\ & = \underbrace{ E[Y_{i}(1) - Y_{i}(0) \mid D_{i} = 1] }_{ATT} + \underbrace{ E[Y_{i}(0) \mid D_{i} = 1] - E[Y_{i}(0) \mid D_{i} = 0] }_{\text{Selection bias}}. \end{align*}\]

    2. Assume the potential outcomes \(Y_{i}(1), Y_{i}(0)\) are independent of the treatment \(D_{i}\), which is written as \[\begin{align*} Y(1), Y(0) \perp\!\!\!\perp D. \end{align*} \tag{2}\]

      1. Why is the selection bias now \(0\)?
      2. What does the naive comparison now equal?
      3. How does this relate to identification?
      4. What does the naive comparison also equal because of Equation 2?

    3. Assume instead the potential outcomes \(Y_{i}(1), Y_{i}(0)\) are independent of the treatment \(D_{i}\) conditional on \(X_{i}\):

      \[\begin{align*} Y(1), Y(0) \perp\!\!\!\perp D \mid X, \end{align*} \tag{3}\]

      1. Show how the ATE, \(E[Y_{i}(1) - Y_{i}(0)]\), can be identified as:

        \[\begin{align*} E[Y_{i}(1) - Y_{i}(0)] = E\{ E[Y_{i}\mid D_{i} = 1, X_{i}] - E[Y_{i}\mid D_{i} = 0, X_{i}] \} \end{align*} \tag{4}\]

        using Equation 1 and Equation 3.

Exercise 2 - Estimators

The data for this exercise can be downloaded here.

  1. Consider the linear model:

    \[\begin{align*} Y_{i} = \beta_{0} + \beta_{1} D_{i} + \beta_{2}X_{i} + \varepsilon_{i}, \quad i = 1, \ldots, n. \end{align*}\]

    1. Estimate \(\beta_1\) using OLS. You can start from the snippet:

      import statsmodels.formula.api as smf


# Assuming loaded data is named `df`
m = smf.ols("Y ~ D + X", data=df).fit()

      Note: you might have to install statmodels

  2. Fit separate regressions for treated and control groups.

    md0 = smf.ols("Y ~ D + X", data=df_sim.filter(pl.col("D").eq(0))).fit()
md1 = smf.ols("Y ~ D + X", data=df_sim.filter(pl.col("D").eq(1))).fit()

    These two models approximate \[\begin{align*} m_0(x) = E[Y \mid D = 0, X = x], \qquad m_1(x) = E[Y \mid D = 1, X = x]. \end{align*}\]

  3. Compute the plug-in ATE estimator

    \[\begin{align*} \hat\tau_{\text{plugin}} = \frac{1}{n}\sum_i \left( \hat m_1(X_i) - \hat m_0(X_i) \right) \end{align*}\]

    using the fitted models to predict potential outcomes for everyone. When predicting using md0 you should set \(D = 0\) for all individuals in the data. Similarly, when predicting using md1 you should set \(D = 1\) for all individuals in the data. The plug-in estimate is the average of the difference between the two predicted vectors.

  4. The same estimate can be computed using

    \[\begin{align*} Y_{i} = \beta_{0} + \beta_{1} D_{i} + \gamma \bar{X}_{i} + \delta D_i \bar{X}_{i} + \varepsilon_{i}, \quad i = 1, \ldots, n. \end{align*}\]

    where \(\bar{X}_{i}\) is the sample average of \(X_{i}\). Try computing it this way.

  5. Finally, estimate the following naive model:

    \[\begin{align*} Y_{i} = \beta_{0} + \beta_{1} D_{i} + \varepsilon_{i}, \quad i = 1, \ldots, n. \end{align*}\]

    using OLS.

  6. Compare all the estimates from the previous exercises. Relate your estimates to the conditional independence assumption, Equation 3.
